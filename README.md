# Examen React

Entrega de los ejercicios prácticos de React.

## Componentes creados

- `TarjetaCancion.jsx`: Renderizado de tarjetas con portada o placeholder gris y marca de favorita.
- `EditorPlaylist.jsx`: Añadir, eliminar y alternar favoritas en una playlist usando estado inmutable y estado derivado.
- `RelojMundial.jsx`: Selector de zonas horarias con `setInterval`, cleanup en `useEffect` y sincronización con el título de la página.
- `InputConContador.jsx`: Input controlado con botón para enfocar con `useRef` y contador de renders sin disparar re-renderizados.
- `IdiomaContext.jsx` y `Saludo.jsx`: Contexto global para alternar entre español e inglés.

## Instalación y ejecución

```bash
npm install
npm run dev
```
